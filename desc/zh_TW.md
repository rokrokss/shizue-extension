🌸 Shizue 是在 Chrome 側邊欄中使用的 AI 助理。可以對照原文和譯文觀看影片、瀏覽網頁，讓 Shizue 在分頁裡替你點擊完成任務，不必切換分頁就能和 AI 對話，也能一鍵總結正在閱讀的內容。

Shizue 是免費的開源軟體（MIT）。你可以使用 ChatGPT 登入，用自己的方案；也可以使用自備的 AI 供應商 API 金鑰，依實際用量付費。還可以使用在自己電腦上執行的模型，不需要金鑰，也不會產生費用。Shizue 本身不需要註冊帳號，沒有訂閱，也沒有伺服器。


✨ 功能

🔐 使用 ChatGPT 登入
- 只要登入，不需要 API 金鑰就能使用你現有的方案

🎬 影片雙語字幕
- YouTube：一邊看一邊在原文下方顯示你的語言字幕，按 A 或 D 鍵跳到上一句或下一句
- Twitch：支援實況直播與重播，根據實況主字幕或語音辨識，由 Chrome 在裝置上免費翻譯
- Netflix：作品有你所用語言的字幕時，直接顯示在原文下方；沒有的話，會在播放前預先準備好

🕹️ 瀏覽器操作
- 告訴 Shizue 要做什麼，它會在分頁中點擊、輸入、選擇和捲動，一步一步完成，每一步都顯示在側邊欄中
- 傳送、刪除或付款前會先徵得你的同意，也絕不會在密碼或信用卡欄位中輸入
- 前往本次任務尚未用過的網站前會先詢問，較長的任務開始前會先列出計畫和要用到的網站
- 網頁從其他網站嵌入的預訂、聯絡和結帳表單也能操作
- 頁面需要你處理時（例如登入或 CAPTCHA），會把分頁交給你，點擊「繼續」後再接著進行
- 開啟「在獨立分頁中執行」後，它會在自己的分頁中作業，你可以繼續使用自己的分頁
- 從頁面上 Shizue 選單的最上方即可開始

💬 側邊欄對話
- 隨時按 Ctrl+Shift+E（Mac 為 Cmd+Shift+E）即可開啟
- 可以上傳圖片，也能從歷史記錄回到先前的對話
- 可以上傳 PDF 以及 Word、Excel、PowerPoint、HWPX 和 EPUB 檔案，並針對內容提問
- 「在開啟的分頁中尋找」和「在歷史記錄中尋找」：提問時可以帶入能回答問題的已開啟分頁、過去的對話和造訪過的網頁。歷史記錄中找到的內容會先給你看，由你決定是否傳送
- 建立新對話時，會列出網頁仍開著的近期對話供你接著聊，已輸入但未傳送的內容也會留在輸入框中

📋 頁面總結
- 一鍵產生摘要，接著針對它繼續提問

🌐 網頁雙語對照
- 譯文顯示在每個段落下方，原文留在原處

🎯 右鍵選單
- 所選文字：翻譯、解釋、總結、修正文法
- 「在本頁中查含義」：選取名字或術語，即可根據本頁內容獲得解釋，只使用你已讀過的部分
- 連結：不必開啟即可預覽頁面重點和閱讀時間
- 表單：用另一個開啟的分頁填寫，例如履歷或訂單。你會先核對填入的值，Shizue 絕不會送出表單
- 圖片：描述內容、擷取文字、翻譯圖片。看漫畫和條漫時，可以一次翻譯頁面上的所有圖片
- 整個頁面：翻譯、總結

📝 備忘錄
- 輸入時自動儲存，支援置頂和搜尋

🎨 其他
- 依模型統計的 Token 用量圖表
- 淺色和深色主題
- 介面支援 23 種語言


🔒 隱私
- 登入資訊、金鑰、對話記錄和備忘錄只會儲存在瀏覽器中
- 使用某項功能時，只有該功能需要的內容會從瀏覽器直接傳送到所選的 AI 供應商
- 瀏覽器操作絕不會讀取密碼或信用卡欄位中的內容。使用支援圖片的模型時，還能查看所操作分頁中可見的部分
- 歷史記錄搜尋在你的電腦上進行，找到的內容除非你選擇傳送，否則不會送出
- 使用本機模型時，任何內容都不會離開你的電腦
- 不使用分析或追蹤工具
- 原始碼：https://github.com/rokrokss/shizue


🚀 開始使用
1. 安裝 Shizue，按 Ctrl+Shift+E（Mac 為 Cmd+Shift+E）開啟側邊欄
2. 使用 ChatGPT 登入、貼上你的 API 金鑰，或連接在自己電腦上執行的模型
3. 開啟任何網站，開始提問
