🌸 Shizue คือผู้ช่วย AI ที่ใช้งานในแผงด้านข้างของ Chrome ดูวิดีโอหรืออ่านหน้าเว็บโดยเห็นทั้งต้นฉบับและคำแปลไปพร้อมกัน ให้ Shizue คลิกจัดการงานในแท็บแทนคุณ แชทกับ AI ได้โดยไม่ต้องสลับแท็บ และสรุปสิ่งที่กำลังอ่านได้ในคลิกเดียว

Shizue ใช้งานฟรีและเป็นโอเพนซอร์ส (MIT) ลงชื่อเข้าใช้ด้วย ChatGPT เพื่อใช้แพ็กเกจของคุณ หรือใช้คีย์ API ของคุณเองจากผู้ให้บริการ AI ที่คุณเลือกและจ่ายตามที่ใช้จริงเท่านั้น หรือจะใช้โมเดลที่รันบนคอมพิวเตอร์ของคุณเองก็ได้ โดยไม่ต้องใช้คีย์และไม่มีค่าใช้จ่าย ตัว Shizue เองไม่ต้องสร้างบัญชี ไม่มีค่าสมาชิก และไม่มีเซิร์ฟเวอร์


✨ ฟีเจอร์

🔐 ลงชื่อเข้าใช้ด้วย ChatGPT
- แค่ลงชื่อเข้าใช้ก็ใช้แพ็กเกจที่คุณมีอยู่ได้เลย ไม่ต้องใช้คีย์ API

🎬 คำบรรยายวิดีโอสองภาษา
- YouTube: ภาษาของคุณแสดงอยู่ใต้บรรทัดต้นฉบับระหว่างดู กด A หรือ D เพื่อไปยังบรรทัดก่อนหน้าหรือถัดไป
- Twitch: ทั้งไลฟ์สดและไลฟ์ย้อนหลัง จากคำบรรยายของสตรีมเมอร์หรือการรู้จำเสียงพูด โดย Chrome แปลให้ในเครื่องได้ฟรี
- Netflix: ถ้าเรื่องที่ดูมีคำบรรยายภาษาของคุณ จะแสดงไว้ใต้ต้นฉบับ ถ้าไม่มี ก็จะเตรียมไว้ให้ก่อนเล่นถึง

🕹️ ควบคุมเบราว์เซอร์
- บอก Shizue ว่าจะให้ทำอะไร แล้ว Shizue จะคลิก พิมพ์ เลือก และเลื่อนหน้าในแท็บของคุณทีละขั้นตอน พร้อมแสดงแต่ละขั้นตอนในแผง
- ถามคุณก่อนทุกครั้งที่จะส่ง ลบ หรือชำระเงิน และไม่พิมพ์ลงในช่องรหัสผ่านหรือช่องข้อมูลบัตรเด็ดขาด
- บนเว็บไซต์ที่งานนั้นยังไม่เคยเข้า จะถามคุณก่อน และงานที่ยาวขึ้นจะแสดงแผนและเว็บไซต์ที่จะใช้ก่อนเริ่ม
- แบบฟอร์มจอง ติดต่อ และชำระเงินที่หน้าเว็บฝังมาจากเว็บไซต์อื่นก็ใช้ได้เช่นกัน
- เมื่อหน้าเว็บต้องให้คุณทำเอง เช่น ลงชื่อเข้าใช้หรือ CAPTCHA จะส่งแท็บให้คุณจัดการ แล้วทำงานต่อเมื่อคุณกดทำต่อ
- เปิด “ทำงานในแท็บแยก” แล้ว Shizue จะทำงานในแท็บของตัวเอง ขณะที่คุณใช้แท็บของคุณต่อได้ตามปกติ
- เริ่มได้จากรายการบนสุดในเมนู Shizue บนหน้าเว็บ

💬 แชทในแผงด้านข้าง
- เปิดได้จากทุกที่ด้วย Ctrl+Shift+E (Cmd+Shift+E บน Mac)
- แนบรูปภาพได้ และกลับไปเปิดแชทก่อนหน้าได้จากประวัติ
- แนบไฟล์ PDF และไฟล์ Word, Excel, PowerPoint, HWPX และ EPUB แล้วถามเกี่ยวกับไฟล์เหล่านั้นได้
- ค้นหาในแท็บที่เปิดอยู่ และค้นหาในประวัติ: แต่ละคำถามดึงแท็บที่เปิดอยู่ แชทก่อนหน้า และหน้าที่เคยเข้าชมซึ่งตอบคำถามนั้นมาใช้ได้ สิ่งที่พบจากประวัติจะแสดงให้คุณดูก่อน และคุณเลือกเองว่าจะส่งหรือไม่
- แชทใหม่จะเสนอให้ทำต่อจากแชทล่าสุดที่หน้าเว็บยังเปิดอยู่ และข้อความที่พิมพ์ไว้แต่ยังไม่ได้ส่งจะยังอยู่ในช่องแชท

📋 สรุปหน้าเว็บ
- รับบทสรุปในคลิกเดียว แล้วถามต่อเกี่ยวกับเนื้อหานั้นได้เลย

🌐 หน้าเว็บสองภาษา
- คำแปลจะแสดงใต้แต่ละย่อหน้า ต้นฉบับจึงยังอยู่ที่เดิม

🎯 เมนูคลิกขวา
- ข้อความที่เลือก: แปล อธิบาย สรุป และแก้ไวยากรณ์
- หาความหมายในหน้านี้: เลือกชื่อหรือคำศัพท์ แล้วรับคำอธิบายจากเนื้อหาในหน้า โดยใช้เฉพาะส่วนที่คุณอ่านมาแล้ว
- ลิงก์: ดูประเด็นสำคัญและเวลาอ่านของหน้าเว็บได้โดยไม่ต้องเปิด
- แบบฟอร์ม: กรอกจากแท็บอื่นที่เปิดอยู่ เช่น เรซูเม่หรือคำสั่งซื้อ คุณตรวจค่าก่อน และ Shizue ไม่ส่งแบบฟอร์มให้เด็ดขาด
- รูปภาพ: อธิบายภาพ ดึงข้อความจากภาพ และแปลรูปภาพ สำหรับมังงะและเว็บตูน แปลรูปภาพทั้งหมดในหน้าได้ในครั้งเดียว
- ทั้งหน้า: แปลและสรุป

📝 บันทึก
- บันทึกอัตโนมัติระหว่างพิมพ์ ปักหมุดและค้นหาได้

🎨 อื่น ๆ
- กราฟการใช้โทเค็นแยกตามโมเดล
- ธีมสว่างและธีมมืด
- อินเทอร์เฟซรองรับ 23 ภาษา


🔒 ความเป็นส่วนตัว
- ข้อมูลการลงชื่อเข้าใช้ คีย์ ประวัติแชท และบันทึก เก็บไว้ในเบราว์เซอร์เท่านั้น
- เมื่อใช้ฟีเจอร์ใด จะส่งเฉพาะเนื้อหาที่ฟีเจอร์นั้นต้องใช้ จากเบราว์เซอร์ตรงไปยังผู้ให้บริการ AI ที่เลือกไว้
- ฟีเจอร์ควบคุมเบราว์เซอร์ไม่อ่านสิ่งที่อยู่ในช่องรหัสผ่านหรือช่องข้อมูลบัตรเด็ดขาด เมื่อใช้โมเดลที่อ่านรูปภาพได้ ยังดูส่วนที่มองเห็นของแท็บที่ทำงานอยู่ได้ด้วย
- การค้นหาในประวัติทำงานบนคอมพิวเตอร์ของคุณ และสิ่งที่พบจะไม่ถูกส่งออกไป เว้นแต่คุณเลือกส่งเอง
- เมื่อใช้โมเดลในเครื่อง จะไม่มีข้อมูลใดออกไปนอกคอมพิวเตอร์ของคุณ
- ไม่มีระบบวิเคราะห์หรือติดตามการใช้งาน
